拥挤度 & 夏普比 — 使用说明 展开

拥挤度 (crowding_ratio) = 20日均量 ÷ 120日均量。反映短期交易拥挤程度。

> 1.5 = 过热 — 短期追涨资金密集，回调风险大
1.0 ~ 1.5 = 偏热 — 交易活跃，注意仓位
< 1.0 = 正常 — 交易冷清或筹码稳定

夏普比 (sharpe_60d) = (60日年化收益率 − 无风险利率) ÷ 年化波动率。衡量风险调整后收益。

> 1.0 = 优秀 — 承担相同风险获得更高回报
0.5 ~ 1.0 = 良好 — 风险收益比合理
< 0.5 = 一般 — 风险收益比不佳

应用方法

拥挤度低(<1.0) + 夏普高(>0.8) → 关注买入时机，市场情绪冷静且风险收益比合理
拥挤度高(>1.5) → 短期追涨风险大，注意止盈或减仓
夏普持续走低 → 说明近期波动加大或收益下滑，重新评估持仓

筹码形态 — 六大形态判定说明 展开

筹码集中度 = COST算法计算的筹码锁定程度。>12% 集高度集中, 8-12% 中度集中, <5% 分散。

六大形态

◆ 低位单峰密集 — 集中度≥12% + 单峰 + 价格在峰值附近。主力吸筹完毕，筹码高度锁定 → 买入
◆ 洗盘回归密集 — 集中度≥10% + 单峰 + 价格回调<20%。主力拉升后洗盘，底部筹码未松动 → 加仓
◆ 多峰密集上行 — 8%≤集中度<12% + 多峰。趋势拉升中筹码滚雪球式换手 → 持有/上调止损
◆ 向上突破高位密集 — 集中度≥8% + 价格高于峰值区。突破高位筹码密集区 → 逐步减仓
◆ 上峰消失高位分散 — 集中度从高变低(下降>30%) 或 集中度<5%且之前>8%。主力已出货，散户站岗 → 强制清仓
◆ 筹码分散 — 集中度<5%持续。无主力迹象，筹码自由流通 → 观望

怎么看

集中度持续上升 + 单峰 → 主力锁仓，关注突破信号
集中度从高变低 + 价格下跌 → 主力出货，注意止损
多峰结构 → 中线持有，但需警惕最高峰是否开始松动
