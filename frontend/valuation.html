📊 PE 百分位使用说明
📌概念
PE 百分位 = 当前市盈率在近 3 年历史中的位置。
例如 20% = PE 比过去 80% 的时间都低（便宜）。
🎨色区含义
绿色 (0-20%) = 低估区
黄色 (20-80%) = 合理区
红色 (80-100%) = 高估区
💡注意事项
百分位仅反映历史位置，不绝对代表贵贱。周期股在底部 PE 反而最高，需结合行业阶段判断。历史数据时间越长，百分位参考价值越大。

📘 什么是蒙特卡洛仿真？
对估值模型的关键输入参数（营收增速、WACC、毛利率等）设定概率分布，计算机随机采样 N 次，观察输出结果的分布形态。帮助理解"估值的不确定性有多大"。
🎯 操作步骤
1. 选择估值方法 — 先在估值仪表盘计算过某股票
2. 选择关注的输出字段（如 weighted_target）
3. 对每个参数设定分布类型：   正态分布：最常用，参数围绕均值浮动   均匀分布：只知道大致范围时用   三角分布：知道乐观/悲观/最可能值时用
4. 点 "运行仿真" 观察结果分布
📊 结果解读
- 直方图：横轴 = 估值价格，纵轴 = 出现频率
- 均值/中位数：最可能的估值中枢
- P10/P90：90%/10% 的概率估值落在此值以上/以下
- 偏度：均值 > 中位数 = 右偏，上行空间大于下行风险
