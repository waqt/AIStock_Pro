# AIStock_Pro 数据同步模块技术规格书 (Data Sync Specification)

## 1. 模块概述
数据同步模块是 AIStock_Pro 的核心引擎，负责从外部数据源（新浪、东方财富、AkShare 等）抓取行情，进行增量清洗，并驱动量化指标算子进行逻辑推演。

---

## 2. 详细功能规格

### 2.1 行情同步 (Market Data Sync)
*   **同步内容**：
    *   日线 OHLC（高、开、低、收）。
    *   成交量 (Volume) 与成交额 (Amount)。
    *   涨跌幅 (Pct Change)。
*   **同步策略**：
    *   **冷启动模式**：若数据库中无该股历史数据，自动抓取过去 2 年（或全量）的日线。
    *   **热更新模式 (增量)**：对比数据库中最新的 `trade_date` 与当前交易日，仅抓取缺失日期的数据，降低 API 负载。
*   **后置触发**：同步完成后，自动触发 `Position` 表的现价更新与账户盈亏重算。

### 2.2 指标计算 (Indicator Engine)
*   **计算范围**：包含基础趋势指标（MA, MACD, KDJ）与自定义逻辑指标。
*   **指标管理页面 (规划中)**：
    *   展示所有可用指标的数学定义与参数。
    *   支持将特定指标（如 BOLL, MA250）通过 API 注入 K 线组件进行叠加展示。
*   **触发机制**：支持“行情同步后自动计算”或“手动重算所有指标”。

### 2.3 数据源透明化 (Data Source Transparency)
*   **优先级看板**：展示当前系统配置的数据源链路（例如：`AkShare > Sina > EastMoney`）。
*   **实时反馈**：在同步任务中实时展示本次请求命中的数据源名称及其延迟状态。

### 2.4 任务进度看板 (Task Monitor)
*   **监控要素**：
    *   任务名称（全量同步/行情同步/指标重算）。
    *   启动时间与耗时统计。
    *   **节点级追踪**：展示当前正处于 `FETCHING`（抓取）、`CALCULATING`（计算）还是 `SAVING`（落库）阶段。
*   **人工干预**：支持 `SIGKILL` 级的中断请求，确保在服务器压力过大时可手动释放资源。

### 2.5 数据健康检查 (Data Health Check)
*   **行情体检**：
    *   列出所有已同步股票。
    *   显示各股最新行情日期（用于排查数据断层）。
    *   展示最新收盘价。
*   **指标体检**：
    *   展示指标覆盖率。
    *   **结构化展示**：对于复杂指标（如 MA5/10/20），以 JSON 结构体形式展示最新数值快照。

## 3. 数据模型设计 (核心字段)

### `analysis_tasks` (任务记录)
| 字段 | 类型 | 描述 |
| :--- | :--- | :--- |
| `id` | UUID | 任务唯一标识 |
| `task_type` | String | 任务类型 |
| `status` | Enum | PENDING, RUNNING, SUCCESS, CANCELLED, FAILED |
| `current_step` | String | 当前执行节点 |
| `result_summary` | Text | 进度描述文字 |

## 4. 后续迭代路线
1.  **Phase 1**: 实现增量同步算法，替换目前的简单覆盖逻辑。

3.  **Phase 3**: 开发专门的“数据体检” UI 页面。
